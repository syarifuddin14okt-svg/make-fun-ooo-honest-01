One brutally honest but still polite out-of-office auto-reply, in a
single sentence of at most 200 characters. It admits the truth every
employee only says privately — the inbox is a lost cause — and still
promises a reply, so a manager would let it stand.

> "I'm out of office until Monday — my inbox has 847 unread emails and I won't pretend I'll read them all, but I'll reply to yours the moment the guilt outweighs the dread."

Run `python3 main.py`; it writes the reply to `/output/entry.txt`.
